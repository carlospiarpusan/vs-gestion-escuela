# Limpieza local del proyecto

Se eliminaron aproximadamente 12.15 GB decimales (11.32 GiB), calculados a partir
de `du -sk` de los archivos antes de retirarlos. El espacio fisico recuperado
puede diferir si APFS mantiene instantaneas o bloques compartidos.

## Eliminado

- `.next`: compilacion y cache web, despues de verificar `npm run build`.
- `mobile/node_modules`: dependencias reinstalables con su lockfile.
- `mobile/android/app/build`, `mobile/android/app/.cxx`, `mobile/android/build`
  y `mobile/android/.gradle`: compilaciones y caches Android.
- `mobile/.expo`: estado temporal de Expo.
- `output/android/avd`: emulador temporal usado en pruebas.
- `output/android/native-check`: binarios extraidos para verificacion.
- `output/android/previous`: copias antiguas de instaladores.
- APK/AAB de las versiones 1.0.3-4, 1.0.4-5 y 1.0.5-6.

## Conservado

- Todo el codigo, migraciones, pruebas, datos de origen y configuracion.
- `.env`, credenciales, firmas y claves Android. No se modificaron.
- APK y AAB 1.0.7-8 enviados a Google Play, mas 1.0.6-7 como respaldo.
- Informes y scripts de revision de Google Play.
- Dependencias web para seguir trabajando y ejecutar las pruebas.
- Historial `.git` completo (aproximadamente 6 GiB); no se reescribio ni purgo.

Los SHA-256 de los cuatro instaladores conservados y de `debug.keystore` fueron
iguales antes y despues de la limpieza. AAB de produccion conservado:

`cd04af488bfee95a6c2302de8f733b25996e13c400db00faa5326d65f218c0f4`

El proyecto completo paso a ocupar aproximadamente 7.5 GiB, incluyendo Git.
Se agregaron exclusiones de Git para emuladores, binarios y capturas regenerables
para evitar volver a incorporar estos archivos por accidente.

## Regenerar cuando sea necesario

```sh
# Dependencias Android/Expo
npm --prefix mobile ci

# Compilacion web
npm run build
```

La compilacion Android seguira el procedimiento de `mobile/PLAY_STORE_RELEASE.md`.
La limpieza no cambia los despliegues de Vercel ni los archivos ya subidos a Play.
